# chess.io

Браузерные шахматы с русским интерфейсом: играйте с другом на одном устройстве или с компьютером, выбирайте контроль времени и продолжайте сохранённую партию.

**Сайт:** [panterafd.github.io/chess.io](https://panterafd.github.io/chess.io/). Обновления появляются на сайте после слияния изменений в ветку, из которой настроен GitHub Pages.

## Возможности

- Проверка допустимых ходов и безопасности короля; шах, мат, пат.
- Обе рокировки, взятие на проходе и превращение в ферзя, ладью, слона или коня.
- Автоматические ничьи при троекратном повторении, правиле 50 ходов и недостатке материала.
- Компьютер с тремя уровнями, выбор белых, чёрных или случайной стороны; подсказки по позиции.
- Часы: без ограничения, **3+2**, **5+0**, **10+0**, **15+10**. Реальное прошедшее время учитывается даже после сворачивания или перезагрузки страницы.
- История ходов в SAN, взятые фигуры и материальный перевес, подсветка последнего хода и шаха.
- Отмена хода, разворот доски, переключение координат, необязательный звук.
- Автосохранение в браузере, экспорт партии в **PGN**, копирование позиции в **FEN**.
- Адаптивный интерфейс, SVG-фигуры, клавиатурное управление и подписи для программ чтения с экрана.

Нет регистрации, сервера партий, внешних шрифтов, аналитики или CDN. Это локальная игра: режим «С другом» означает двух игроков на одном устройстве, а не сетевой матч. Статические файлы можно размещать в подпапке, например `/chess.io/`.

## Быстрый запуск

Нужен **Node.js 22 или новее**.

```sh
git clone https://github.com/Panterafd/chess.io.git
cd chess.io
npm start
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Для запуска сайта устанавливать npm-зависимости не нужно: браузерная копия шахматной библиотеки уже находится в `vendor/`. Открытие `index.html` через `file://` не поддерживается: ES-модулям и Web Worker требуется HTTP-сервер.

Для разработки и тестов:

```sh
npm ci
npx playwright install chromium
npm run check
```

На Linux для установки системных зависимостей браузера: `npx playwright install --with-deps chromium`.

Если на Windows уже установлен Edge, можно использовать его без загрузки Chromium:

```powershell
$env:PLAYWRIGHT_CHANNEL = 'msedge'
npm run test:e2e
```

## Управление

| Действие              | Как выполнить                                                                 |
| --------------------- | ----------------------------------------------------------------------------- |
| Сделать ход           | Нажмите на свою фигуру, затем на подсвеченную клетку                          |
| Выбрать другую фигуру | Нажмите на другую фигуру своего цвета                                         |
| Снять выбор           | Повторное нажатие на фигуру или `Escape`                                      |
| Клавиатурный ход      | `Tab` до доски; стрелки для перемещения; `Enter` или пробел для выбора и хода |
| Рокировка             | Передвиньте короля на две клетки к ладье                                      |
| Превращение           | Дойдите пешкой до последней горизонтали и выберите фигуру в диалоге           |
| Перевернуть доску     | Кнопка `⇅` или клавиша `F`                                                    |
| Отменить ход          | Кнопка «Отменить» или клавиша `U`                                             |
| Получить подсказку    | Кнопка «Подсказка»: начальная и конечная клетки выделятся золотым             |
| Сохранить запись      | Кнопка «↓ PGN»                                                                |
| Скопировать позицию   | Кнопка «Скопировать FEN» внизу страницы                                       |

## Правила партии

Часы начинают отсчёт **после первого хода**, без бесплатной паузы на свёрнутой странице или в диалогах. Добавление применяется после каждого завершённого хода. При отмене возвращаются часы непосредственно перед отменённым ходом: уже потраченное на него время не возвращается.

В игре с компьютером отменяются ход игрока и ответ компьютера. Пока компьютер ещё думает, отменяется только ход игрока. Если вы играете чёрными, первый ход компьютера не отменяется отдельно.

Игра любительская. Ничьи по троекратному повторению и 50 ходам фиксируются автоматически, без процедуры требования ничьей. Соглашение на ничью доступно двум местным игрокам. Мат, пат и недостаток материала проверяет [chess.js](https://github.com/jhlywa/chess.js).

При просрочке часов очевидное отсутствие возможности мата у соперника (голый король, одна лёгкая фигура против голого короля, только одноцветные слоны) даёт ничью. Для редких составных «мёртвых позиций» не реализован исчерпывающий анализ возможности мата; это не турнирный арбитр.

Компьютер — собственный ограниченный по времени поиск, **не Stockfish**. Уровни меняют глубину и бюджет поиска; рейтинг Elo не заявляется. На слабом устройстве поиск может завершиться на меньшей глубине. Подсказка — возможное продолжение, а не гарантия лучшего хода.

## Сохранения и приватность

Партия хранится в `localStorage` под ключом `chess.io.game.v1`, настройки интерфейса — `chess.io.preferences.v1`. Сохраняются полная история, позиция, часы и результат; повторение позиций остаётся корректным после перезагрузки. Никакие данные партии не отправляются на сервер.

Сохранение привязано к браузеру и адресу сайта. Очистка данных браузера или приватный режим могут удалить его. Если запись недоступна, игра продолжит работать и покажет предупреждение. Для архива используйте PGN. Импорт PGN/FEN пока не поддерживается. Открывайте одну активную игровую вкладку: синхронизации нескольких вкладок нет.

## Структура и проверки

| Путь                                    | Назначение                                                     |
| --------------------------------------- | -------------------------------------------------------------- |
| `index.html`, `styles.css`              | Разметка, диалоги и адаптивный дизайн                          |
| `src/game.js`                           | Правила партии, часы, отмена, сохранения и PGN                 |
| `src/app.js`                            | Взаимодействие пользователя, отрисовка и жизненный цикл Worker |
| `src/engine.js`, `src/engine-worker.js` | Поиск хода компьютером вне основного потока                    |
| `src/pieces.js`                         | Локальные SVG-фигуры                                           |
| `vendor/`                               | Зафиксированная браузерная копия chess.js и её лицензия        |
| `tests/`                                | Тесты правил, часов, поиска и браузерных сценариев             |
| `scripts/`                              | Сервер разработки и воспроизводимое обновление vendor          |

```sh
npm test                 # модульные тесты; браузер не нужен
npm run test:e2e         # браузерные проверки: desktop + mobile
npm run vendor          # обновить vendor из установленной точной версии chess.js
npm run vendor -- --check # проверить совпадение vendor и зависимости
npm run check           # все проверки
npm run format          # единое форматирование исходников и документации
```

Тесты проверяют эталонные количества ходов (perft), связки, специальные ходы, окончания, восстановление, часы, тактику компьютера, отмену устаревшего Worker, управление с клавиатуры, отказ хранилища и мобильную геометрию. GitHub Actions запускает их для push и pull request. Мобильные проверки эмулируют телефон в Chromium; реальные Safari/iOS требуют отдельной проверки.

Подробнее: [архитектура](docs/ARCHITECTURE.md), [проверка и публикация](docs/TESTING.md), [журнал изменений](CHANGELOG.md).

## Публикация

Для GitHub Pages используйте **Settings → Pages → Deploy from a branch → main → / (root)**. Сборка не нужна: `index.html`, `styles.css`, `favicon.svg`, `src/` и `vendor/` готовы к статическому хостингу. Изменения в отдельной ветке/PR сами по себе не обновляют публичную игру. CI только проверяет код и не выполняет развёртывание.
